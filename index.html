⚙️ Google Cloud OAuth 셋업

1️⃣ Google Cloud 프로젝트 생성
console.cloud.google.com/projectcreate 열기 → 프로젝트 이름 (예: icde-personal) → 만들기

2️⃣ Calendar API 활성화
좌측 메뉴 → "API 및 서비스" → "라이브러리" → "Google Calendar API" 검색 → 사용

3️⃣ OAuth 동의 화면
"OAuth 동의 화면" → User Type: 외부 → 만들기
앱 이름: I Can Do Everything
지원 이메일: 본인 이메일
범위 추가: .../auth/calendar ("Google Calendar API" 검색)
테스트 사용자: 본인 Gmail 등록 (앱이 게시되지 않은 상태에서 필수)

4️⃣ OAuth 2.0 클라이언트 ID 만들기
"사용자 인증 정보" → "+ 사용자 인증 정보 만들기" → "OAuth 클라이언트 ID"
애플리케이션 유형: 웹 애플리케이션
이름: ICDE Web
승인된 자바스크립트 출처에 다음 모두 추가:
https://i-can-do-everything-9b73a.web.app https://i-can-do-everything-9b73a.firebaseapp.com http://localhost:8765 승인된 리디렉션 URI는 비워두세요 (Implicit flow). 만들기 → 클라이언트 ID 복사

5️⃣ 이 앱에 붙여넣기
위에서 복사한 클라이언트 ID를 설정의 "Client ID" 입력란에 붙여넣고 "🔗 연결" 클릭. 새 창에서 Google 로그인하면 자동으로 전용 캘린더 "I Can Do Everything"가 만들어지고 동기화 시작됩니다.

주의: OAuth Implicit flow는 토큰이 ~1시간 만료. 만료 후 첫 동기화 시 자동으로 silent 재인증 시도. 실패하면 "🔗 다시 연결" 표시.
앱이 publish되지 않은 동안엔 OAuth 동의 화면에 "확인되지 않은 앱" 경고가 나옵니다 — "고급 → 안전하지 않은 페이지로 이동"으로 통과.

⚙️ 설정

앱 → Cal: 마감 있는 todos, 타임박스, 마일스톤 자동 push.
Cal → 앱: 전용 "I Can Do Everything" 캘린더에서 변경 사항 pull.
